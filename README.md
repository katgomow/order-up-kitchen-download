# 🍳 Order Up Kitchen

A cozy café-kitchen to-do board for Windows. Your Notion tasks become order tickets: **cook** them with a focus timer, **serve** them for tips, and spend tips on cute things for your kitchen 🐱🪴📻

## ⬇️ Download

1. Go to **[Releases](../../releases/latest)** and download the **Order-Up-Kitchen-Setup** .exe file
2. Open it. If Windows says **"Windows protected your PC"**, click **More info → Run anyway** (the app just isn't "signed", it's safe)
3. The setup screen walks you through connecting **Notion** (you'll need a free Notion account)
4. A quick tour shows you around. Replay it any time from **⋯ → Take the tour**

The app **updates itself** when a new version comes out ✨
